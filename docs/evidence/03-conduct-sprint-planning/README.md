1. Sprint_1 Backlog: Ordering & Core Selection Increment
Sprint Goal:

Deliver a functional, end-to-end pickup ordering increment with a fixed catalogue (2 participating restaurants, 2 dishes per restaurant), allowing customers to browse restaurants, select items into a cart, schedule a valid pickup time, and submit orders successfully.

2. Sprint_2 Backlog: Merchant Dashboard & Data Validation Increment
Sprint Goal:

Deliver the restaurant order management dashboard and system-wide input validation, enabling restaurant staff to view incoming orders, progress order statuses through defined lifecycles, and allow customers to track real-time fulfillment states.
