# Definition of Done

A Product Backlog Item is considered Done when:
- All acceptance criteria for the PBI are satisfied.
- The required implementaion is completed and function as expected.
- The code has been commited to the shared GitHub repository.
- The code has been reviewed by other team members.
- Required testing has been completed and passed.
- The completed work has been integrated with the main working application.
- No known critical defects remain for the completed PBI.
- The corresponding item on the GitHub Project has been updated to Done.
