# Product Backlog

## Story Point Estimation 
The team used Story Points to estimate the Product Backlog Items using the Fibonacci scale of 1, 2, 3, 5, 8, and 13.
The estimates were based on the relative effort, complexity, and uncertainty of each PBI.

## Top Five Ordering Rationale
The Product Owner (Ziqing Song) ordered the top five PBIs based on customer value and functional dependencies. 
These items form the core customer ordering workflow.
1. **Browse Participating Restaurants**
   This is the starting point of the order process because customers must first choose a participating restaurant for the order.

2. **View Restaurant Menus**
   Customers must be able to see the available menu items before creating an order once they select the restaurant.
   
3. **Add Items to an Order**
   Adding items is a core ordering function and is required for an order to be placed.
   
4. **Select a Pickup Time**
   Pickup time is also required for a pickup order and must be selected before placing the order.
   
5. **Place an Order**
   This PBI completes the customer ordering workflow by submitting the order with items and pickup time to the restaurant.
